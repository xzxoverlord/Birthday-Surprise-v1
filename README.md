# 🎂 Birthday Surprise Website

A special birthday surprise website created with love.

## ✨ Features
- Beautiful animated effects
- Romantic birthday letter
- Photo gallery
- Background piano music
- Interactive birthday cake and gift
- Responsive design for mobile and desktop

## 🛠️ Technologies
- HTML5
- CSS3
- JavaScript

## 📁 Project Structure
- `index.html` – Main website
- `css/style.css` – Website styling
- `js/main.js` – Animations and interactions
- `assets/images/` – Birthday photos
- `assets/music/` – Background music
